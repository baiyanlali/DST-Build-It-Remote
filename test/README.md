# 量子建造回归测试

需要 Python 和 `lupa`（`python -m pip install lupa`）。测试使用 Lupa 的 Lua 5.1 运行时，与 DST 的 Lua 语法版本一致。

在项目目录执行全部测试：

```powershell
python test/all.py
```

同时验证本机安装的《降低客户端卡顿》真实源码：

```powershell
python test/all.py --lag-mod 'D:/SteamLibrary/steamapps/workshop/content/322330/3123234170/modmain.lua'
```

`all.py` 或 `all.sh` 的第一个位置参数可以指定其他版本的量子建造 `modmain.lua`。任意测试失败都会返回非零退出码。未提供 `--lag-mod` 时会明确跳过第三方源码联合测试。

- `harness.lua`：服务端材料检查、取料和实际扣除，共 23 项断言。
- `client.lua`：未打开箱子数据读取、已打开箱子去重、打开容器不覆盖附近总量，共 6 项断言。
- `sync_refresh.lua`：加载真实量子建造代码，模拟服务端容器事件、网络快照传送、客户端刷新任务；验证大箱子完整同步、清空、堆叠变化、移动、固定栏、主机、初始化、事件合并，以及暗影等口袋维度容器（无 Transform）不被计入且不崩溃。可选加载真实优化模组验证兼容性。
- `bench.lua`：现有服务端查询基准，不代表游戏中的客户端帧率。
